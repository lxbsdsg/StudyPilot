# StudyPilot 学习任务中心

本地桌面聚合工具，用于同时登录多个学习平台账号，集中查看课程、未完成任务和截止时间，并设置提醒。

## 支持平台

| 平台 | 当前状态 | 说明 |
|---|---|---|
| 批改网 | 已验证 | 已用测试账号验证 Chromium 登录、待完成列表读取 |
| U校园 | 端点已验证 | 登录端点在线验证通过；需真实账号完成课程抓取验证 |
| WELearn | 待账号验证 | SSO 已改版，适配器使用 Chromium 登录并复用 Cookie |
| 学习通 | 端点已验证 | 登录端点在线验证通过；需真实账号完成课程和作业抓取验证 |

平台状态会写入本地数据库。只要某个平台有账号成功完成一次登录、课程与任务读取，总览就会显示“已验证”。

## 功能

- 多账号、多平台统一管理，账号之间独立并发刷新。
- 聚合课程进度、单元任务、作业和待完成事项。
- 按平台、账号、状态和关键词筛选任务。
- 任务支持标记完成、恢复未完成、打开原始页面。
- 打开任务时复用该账号的本地登录态。
- 手机浏览器打开时优先返回平台移动版；批改网同时提供 Android/iOS 商店入口。
- 提醒支持两种模式：
  - 指定日期和时间。
  - 按任务截止时间设置倒计时（10 分钟到 1 周）。
- 提醒支持一次、每天、每个工作日、每周重复。
- Windows 到点发送系统通知。
- 密码使用 Windows DPAPI 或本地 AES-GCM 加密，不写入前端与日志。
- 本地服务只监听 `127.0.0.1`。

## 运行

双击 `run.bat`。脚本会创建 `.venv`、安装依赖、启动服务并打开浏览器。

默认地址：

```text
http://127.0.0.1:17890/
```

桌面窗口模式：

```bat
run_desktop.bat
```

桌面模式依赖 `pywebview`；如果未安装，会自动回退为浏览器模式。

命令行运行：

```bat
.venv\Scripts\python.exe -m studypilot --no-browser
```

## 数据位置

默认数据目录：

```text
%USERPROFILE%\.studypilot\
```

其中：

- `studypilot.db`：账号、课程缓存、任务和提醒。
- `secret.key`：非 Windows 平台的本地加密密钥。

可通过 `STUDYPILOT_DATA_DIR` 修改数据目录。

## 平台客户端来源

- U校园：复用 `Unipus Helper` 的登录、课程和资源接口。
- WELearn：复用 `Welearn_helper` 的登录、课程和单元接口，并针对新 SSO 增加 Chromium 登录。
- 学习通：参考 `Doraemon` 的登录、课程和作业页面接口。
- 批改网：通过 Chromium 完成官网登录，读取“我的作文”和“未完成”页面。
- ARTEX：参考其 Playwright 浏览器工作流；本项目不包含渗透测试、自动签到、自动答题或提交答案功能。

## 测试

```bat
.venv\Scripts\python.exe -m pytest -q
```

离线测试覆盖存储加密、提醒模式、截止时间解析、批改网页面解析和任务缓存。
